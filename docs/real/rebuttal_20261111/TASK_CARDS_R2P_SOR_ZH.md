# R2P / SOR：现场任务卡与评分规则

本任务卡依据修订稿原任务定义。新的评测独立于原论文15/20结果；以下均为待采集协议。

## R2P — Return-to-Plate

**需要证明的能力：** 两次完整操控之间保留当前episode的原始目的地，调用熟悉搬运动作完成正确回返。

**布置：** 三块视觉相同的盘子，香蕉最初位于其中一块；共同中转区固定。20次来源为盘1/2/3的7/7/6，桌面外观各10次。编号只给记录人员，不作为模型语言/视觉标签。

**阶段：** 初始盘上香蕉 → 抓取并放到共同中转区 → 再次抓取 → 稳定放回原始盘。两次transfer均须由策略完成。

**完整成功：** 全部阶段完成；最后释放在正确原盘并稳定；未超时、未掉落、无人工纠正。仅到中转区、选错盘或没有回返均记失败。单纯选盘的1/3 chance level不是完整操控SR的chance baseline。

**关键记录：** 初始source盘、stage完成时间、回返选择/实际终盘、两次抓取/放置成败、第一次回盘命令前头/腕/proprio与实际语言输入。当前盘的位置与香蕉中转区域应尽可能匹配不同来源历史；记录残余几何差异，不声称物理像素完全相同。

**防泄漏：** 回返指令只说“放回原来的盘子”，不包含编号、左右/前后位置或颜色提示；当前盘子上不放记号；任务ID只用R2P，不编码来源盘；人工手势/视线/桌面纸条不能指示答案。评估用source盘标签不得输入模型。

## SOR — Same-Order-Retrieval

**需要证明的能力：** 完成两次放置后记住实际互动先后，按该顺序完成两次取回；物体熟悉，当前episode顺序变化。

**布置：** 香蕉和橡皮鸭、共同接收区。两种放置顺序各10次。10个几何组各配相反历史；每组两种历史的最终物体位置相同，位置方案在组间平衡，不能用“左边先拿”等几何规则推断顺序。

**阶段：** 按当前逐步cue放置对象1 → 放置对象2 → cue退出当前输入 → 按实际完成的放置顺序取回对象1 → 取回对象2。第一处顺序违反使完整序列失败；仍保留之后实际执行轨迹。

**完整成功：** 两次放置、两次取回及顺序全部满足，物体稳定，时间/步数预算内，无纠正协助。只看最终“两个物体都拿回”不算合格评分。

**关键记录：** requested placement order、completed placement order、first/second retrieved object分别记录；未完成的阶段留空，不能用要求的顺序替换真实完成顺序。保存两次取回前帧、语言输入、recollection有效mask及对应过去cue/完成事件时间戳。

**防泄漏：** 取回时不重新念出顺序，prompt/cached instruction不残留此前cue；当前头/腕画面看不到旧cue；任务ID只有SOR。操作者不在取回阶段提示；当前物体布局与顺序独立。若现场无法满足这些条件，只能将结果解释为多阶段有序操控，不能称为当前观测歧义下的纯记忆证据。

## 两模式一致的评分与记录

- 先验证整个NoRecollection输入路径，包括历史观测、执行动作摘要、历史派生query、重复证据和continuity/thread；保留当前观测/低层控制所需状态。
- 配对模式保持同一任务/语言规则、初态、bank、checkpoint、动作/状态单位、控制器、预算与异常处理。实际采样种子和首次模式按schedule记录。
- `full_task_success`是0/1；各阶段、`history_decision_correct`独立记录真实分母；视频抽样不改变SR。
- 开始后的掉落、错目标、顺序错误、超时、接管和安全停止计入失败并记原因。无法核实终态标unknown，保留原件；不得择优覆盖。
- 评测过程中不把新轨迹写回固定bank，不训练更新模型。每个trial开始重置当前episode记忆，完整trial中途不重置。

## 困难经验库可选项

先固定一个目标task/phase适用性定义，并审计候选来源，采用实测合法经验而非任意合成动作。保持event数量、K、token预算与模型不变；记录实际检索内容和相关候选覆盖。若仅排除某些任务族，将条件命名为family exclusion，不直接命名为“无技能”。

比较自然Full与显式candidate-null时，null应只撤回外部候选影响并保留当前episode recollection；其source/gate/conditioning实际实现须先验证。20对完整trial、gate分布、错误激活和相关覆盖分别报告。该可选对照不能由视频或单个0/0回合替代。
