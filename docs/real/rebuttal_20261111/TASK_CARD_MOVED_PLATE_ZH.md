# 可选第三批：移盘幅度与实际成功率

这张卡直接回应“盘子移动后是否还能复用经验”。优先级低于SOR/R2P共80次历史对照和新增独立示范。它是布局变化测试，不改变原任务语义。

## 固定设置

采用R2P与Full，固定checkpoint、原bank、归一化、指令和控制预算。相对示范参考布局，在每次回合**开始前**移动盘子，随后按原R2P连续完成取出、中转、返回原盘。不得在回合中偷偷换盘；中途物体跟踪是另一项研究。

正式采集前，现场人员根据现有标定与可达空间验证两档平移量d1、d2，并在manifest中填写米制数值、允许误差与四个方向。没有验证过的厘米数不得作为运动指令。以盘中心在桌面坐标系中的实测位移为准，不用像素位移充当物理距离。

三档：d0=原布局、d1=已验证的小幅移位、d2=已验证的较大移位。每档20次，四个方向各5次，三原盘按7/7/6平衡。d0若直接使用主批次Full的20次，须在主批次开始前登记这种共享参照，保持同配置并报告采集时间差；它仍是20个trial，不能重复计入独立样本量。否则另采独立d0批次。新增工作量为40次，或连同独立d0共60次。

## 每次记录

沿用逐次结果和连续头/腕视频，另记录参考盘中心(x,y)、实际中心(x,y)、实际平移向量/范数、方向、初始来源盘、完整SR、回盘决策正确与否、是否到达回盘阶段、取放/掉落/超时/人工介入及当前检索/门控（若可采）。成功仍须两次转移完整、回到原盘、稳定释放且没有人工纠正。

## 报告

逐档给成功数/20、区间、完整失败类型、实际位移分布及关键决策分母。d0/d1/d2的评测顺序交错，布局与历史顺序按冻结清单执行，不按成功重新选择幅度。图中横轴使用实测米/厘米，纵轴用完整任务SR。只在测得范围内表述布局适应性，不写任意位移不变性或未见任务泛化。
