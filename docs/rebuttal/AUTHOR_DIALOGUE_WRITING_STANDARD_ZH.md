# WARM：作者对话口吻与修订论证规范

依据作者2026年11月12日的明确要求，以及三份真人review原文。此规范用于全部后续回复和论文迭代；未完成实验仍受证据准入约束。

## 回复结构

1. 开场感谢该审稿人的具体投入，凝练复述其实际认可的1–2项优点，再说明将逐项回应。Hh4E只认可问题重要性及整体信息整合思路，不能扩写成认可性能或机制有效性。
2. 主体用we/our承担设计、解释、实验和修订责任。每条先直接回答疑问，再给指标、分母、协议和修订位置。技术定义可用客观陈述，不机械给每句加we。
3. 结尾以审稿人可核查的方式说明我们澄清了哪些歧义、补充了什么证据、改写了哪些位置。仅总结已经完成的改动；待完成实验不能出现在“已解决”清单中。
4. 公开回复保持为作者与该审稿人的交流，不出现面向AC/meta-review的宣传、录用目标或索分要求。只有确有严重偏见并另行决定申诉时，才准备独立说明。

## 论文修订方式

- 实验较弱：补充直接证据、完善协议与对照，再以证据巩固原核心观点。不能用更强措辞替代缺失实验，也不因单个开发失败轻率否定全部原稿结果。
- 表述或逻辑有硬伤：替换含混、因果越界或误导的表达，说明实际计算、监督目标、评价对象与适用范围。
- 删除：仅对确实错误且无法修复的内容作有依据处理；普通薄弱实验和不利结果不作隐藏或择优删除。
- 限制集中、精准说明；贡献段和结论正面组织已获证据支持的主张，避免反复追加无关否定。

## 双遍自审

第一遍读者视角：是否像友好而坚定的作者答复，是否正面回应每条问题，开场认可是否忠于review，结尾是否形成明确修订成果。

第二遍科学核心：数值、公式、分母、对照和结论范围是否保真；已知负/unknown是否保留；条件论证是否连同定性方向整段标待验证。即使预想数据理想，也不能据局部repair推导最终SR、据family排除认证真实技能缺失或据零/零推出非劣效。

自审记录具体修改及依据，不用代拟审稿分数证明写作成功。
