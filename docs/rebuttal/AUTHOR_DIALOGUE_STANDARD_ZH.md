# WARM rebuttal的作者交流与论文修订约定

作者于2026年11月12日明确的持续写作要求；后续版本应在证据更新时一并执行。当前落实样本为v27。

## 回复的交流结构

每位审稿人的总回复以感谢开场，准确承接其原review真实认可的贡献，再说明将逐项回答哪些问题。不得替审稿人扩大认可范围：Bbqv认可后果驱动选择及两类记忆的互补，rkWY认可适配与调节复用的灵活性，Hh4E认可问题重要性及综合pipeline；最后一项不能写成对效果的认可。

正文采用we/our解释我们的设计、证据和修订。每个问题先给直接答案，再接最相关的比较、条件、分母和结论；只有需要界定证据范围时才说明限制。语气友好、积极、明确，避免旁观式评述、机械感谢或对审稿人动机的揣测。

每位回复结尾用一个紧凑段落归纳已经澄清的概念、已经增加的证据，以及具体修订位置。归纳必须能由当前论文和证据核对。全文保持和该审稿人的直接交流，不出现显式第四方、meta review、提分要求或评分动机措辞。

完整Markdown和逐评论块应一致；保留20项原weakness/question的字段、序号、hash与回复—证据—论文位置映射，避免润色时遗漏问题。

## 证据与修订的处理

实验支撑薄弱时，优先补齐直接对照和真实结果，并把有支撑的结论明确接回原方法主线。当前v27把原specialist同状态Full/null/Full的稳定性对照从D.1接入主文4.7；它支持单状态的候选影响，不替代总体修复率、完整任务SR或自然缺失技能可靠性。

表达或逻辑不清时，重写定义、条件、因果顺序及比较对象，使之可验证。保留有效的原核心贡献、方法、结果和图表；不能用删除来代替本可完成的澄清或补证。对已核实的实质错误应准确修正，并说明对主张的实际影响。

已完成的不利结果和未知结果按原样保留。为提前自审而撰写的理想结果段落，整段定性方向与数值一起标为PENDING；填写数字本身不会自动放行结论。主张的确定性来自证据，不能来自措辞。

## 每版验收

核对三位原review真实strength与开头、20项覆盖、作者视角、直接答案、真实完成的结尾及37个待证槽。独立检查剥离修辞后的科学主张与证据是否一致。论文使用原完整LaTeX工程编译，再对干净源码ZIP独立重编译，核查正文页数、引用、图表、匿名性、AI use statement和实际页面。回复与论文只保留同一范围、数字、术语和协议。

未经作者授权，不发布OpenReview评论、不上传正式文稿、不向他人发送消息。
